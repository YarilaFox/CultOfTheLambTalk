# Changelog

## 0.5.5

- Improved follower dialogue timing, mouth and voice synchronization, and notification state handling.
- Added optional follower grievance, prison conversation, and reconciliation behavior.
- Fixed a duplicate face appearing behind a follower's head by using the game's native face animation track.
- Known issue: some follower face and mouth animations still look incorrect, particularly on the fox appearance. A further animation fix is planned for a later version.

## 0.5.2

- Added Claude, Grok, OpenCode Console, DeepSeek, OpenClaw Gateway, Hermes Agent, and custom OpenAI-compatible connection options.
- Added separate model IDs and protected keys for each provider, plus configurable local gateway URLs.
- Improved the in-game conversation settings and altar announcement flow.

## 0.5.1

- Added the first Thunderstore package with follower conversations and localized settings.
