# Follower Talk 0.4.1: установка вручную

1. Выйдите из игры. Установите [BepInExPack_CultOfTheLamb 5.4.2101](https://thunderstore.io/c/cult-of-the-lamb/p/BepInEx/BepInExPack_CultOfTheLamb/) в папку игры рядом с `Cult Of The Lamb.exe`. Если BepInEx уже установлен, повторять не нужно.
2. Распакуйте содержимое `FollowerTalk-0.4.1.zip` в корневую папку игры. В итоге должны существовать `BepInEx/plugins/FollowerTalk/FollowerTalk.dll` и `BepInEx/plugins/io.github.xhayper.COTL_API/COTL_API.dll` вместе с папкой `Assets`. COTL_API 0.3.4 уже включён в архив, отдельно скачивать его не нужно. Если он уже установлен, проверьте версию перед заменой; не держите две его копии в разных папках `BepInEx/plugins/`.
3. Запустите игру. В категории настроек «Разговоры» выберите OpenAI API или Gemini API и откройте «Настроить ключ и модель» (окно доступно также по F8). Введите свой API-ключ и сохраните. У последователя появится команда «Поговорить».

Ключи и память создаются локально в `BepInEx/config/` при использовании мода; пакет их не содержит. Подписка на чат-приложение не заменяет API-ключ, запросы могут тарифицироваться отдельно. Для удаления Follower Talk уберите только `BepInEx/plugins/FollowerTalk/`. COTL_API и BepInEx могут использоваться другими модами.

Если команда не появилась, проверьте загрузку обеих DLL в `BepInEx/LogOutput.log`. Архив предназначен для ручной установки в Windows-версию игры; совместимость с другими версиями игры и профилями мод-менеджеров не проверялась. Лицензия стороннего COTL_API находится в `THIRD_PARTY_LICENSES/COTL_API_LICENSE.txt`.
